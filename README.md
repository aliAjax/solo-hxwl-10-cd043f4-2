# 探方地层关系工作台

按探方管理遗迹单位与上下层（叠压）关系的单页应用：自动生成地层序列、
拦截非法关系、控制记录状态流转、保留全部版本，刷新后数据不丢。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无第三方运行时依赖；测试用 Node 内置 `node:test` + esbuild。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5110
```

其他脚本：

```bash
npm test         # 37 项领域测试（正常 + 非法数据）
npm run build    # tsc 严格类型检查 + vite 生产构建
npm run typecheck
npm run dev &    # 先起开发服务器
npm run test:e2e # Playwright：窄屏布局 + 完整交互/刷新持久化（需 npx playwright install chromium）
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 新增遗迹单位、上下层关系 | `UnitForm` / `RelationForm`，统一经 `createStore` 入口落库 |
| 按探方分组生成地层序列 | `buildSequences()`：探方内 Kahn 拓扑排序（上层→下层），深度兜底，阻断单位单列 |
| 拦截自指 / 环路 / 跨探方 / 重复坐标 | `validateRelation()` 与单位字段校验；环路用 DFS 定位完整环路径 |
| 缺失编号或深度标为阻断 | 缺探方不可建档；**缺编号或缺深度都允许登记**并明确标为阻断（未编号可多条），不进正常层位、不能建关系/推进；补齐编号或深度后自动解除阻断 |
| 冲突定位到具体关系 | 冲突日志含探方、两端编号、环路路径；「在图中定位」高亮节点与连线 |
| 草稿 / 待复核 / 已封存 | 三态机；仅领队可推进；发掘队员可将待复核记录退回 |
| 封存后禁止改动 | 封存期间禁止编辑、删除、加/删关系；**领队可将封存记录退回草稿**，退回前的封存版本与退回动作本身均留存版本，退回后才可编辑 |
| 退回草稿保留版本 | 提交、封存、退回、回退均生成 `VersionSnapshot`，永不覆盖旧版本 |
| 版本回退 | 历史版本弹窗中一键恢复为新草稿；回退本身再留一个版本 |
| 筛选 / 统计 / 空状态 / 关系图即时更新 | 所有视图由单一 store 派生，任意动作后同步重渲染 |
| 刷新不丢 | 每次变更写入 `localStorage`（单位、关系、状态、版本、冲突日志） |

## 目录结构

```
src/
  domain/      纯 TS 领域层（不依赖 React）
    types.ts        类型与错误码
    graph.ts        阻断判定、关系校验、环路 DFS、地层序列拓扑
    store.ts        Store：增删改、状态机、版本、冲突日志、统计
    persistence.ts  localStorage 读写与损坏容错
    seed.ts         内置示例（含一条阻断记录 G3）
  ui/          React 组件（表单、台账、SVG 关系图、序列、冲突、统计）
test/
  domain.test.ts   29 项测试：新增/冲突/阻断/状态流转/版本回退/统计/持久化
```

## 测试覆盖

- **正常数据**：建档、同探方叠压、多探方分组、拓扑序列顺序
- **非法数据**：自指、环路（断言环路径 H3→H1→H2→H3）、跨探方、重复/反向关系、
  重复编号、重复坐标、负深度、缺编号/深度
- **阻断**：缺编号/缺深度均可登记并标记阻断、禁止建关系与推进、多条未编号共存、补号撞号仍拦截、补齐后解除
- **状态流转**：非领队拒绝推进、领队推进、封存期间三类改动全拦截、非法跳转、退回留版本、**领队封存退回（非领队被拒）、退回后才可编辑、退回后关系恢复可改**
- **版本回退**：恢复历史字段、生成回退版本、旧链不删、封存拒回退、跨单位版本拒用
- **统计**：空态归零、随新增/冲突/流转/忽略即时变化
- **持久化**：完整序列化还原、还原后封存保护与重复关系约束仍生效、损坏数据安全忽略
